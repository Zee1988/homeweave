## 关键前提

- 构建上下文必须是**仓库根 `.`**（研究 §五 C-1：CI 侧原写的 `./homeweave_app` 取不到 `pnpm-lock.yaml`）。
- 02-02 Task 3 会在 `apps/api/prisma/ENGINE_DECISION` 写下 `NATIVE_ENGINE` 或 `RUST_FREE`。**本计划的引擎断言以该文件为开关**，不靠正文散文约定（上一版缺陷：跨 plan 的"记得删掉"没人检查）。
- 本机**无 Docker**：Task 2 的容器断言全部 CI-only；本地只能验证 Task 1/4/5 的静态部分。

## Tasks

### Task 1 — Dockerfile 与 .dockerignore

- **read_first**: `02-RESEARCH.md` §3.1–3.5、`docs/21_HOME_ASSISTANT_APP_DEPLOYMENT.md`:134、`apps/api/package.json`、`apps/api/prisma/ENGINE_DECISION`
- **files**: `Dockerfile`、`.dockerignore`
- **action**:
  1. 阶段：`base`（node:22-bookworm-slim + `corepack prepare pnpm@9.15.4`）→ `build`（全量安装 + generate + build）→ `prod-deps`（`NODE_ENV=production` 装 prod-only 并 `pnpm deploy --prod /prod`）→ `runtime`。
  2. `runtime` 仅 COPY：`dist/`、生产 `node_modules`（或 deploy 产物）、`prisma/`、最小 `package.json`；`USER node`；`CMD ["node","dist/main.js"]`；`EXPOSE 8099`。
  3. 安装 `openssl ca-certificates`（引擎名依赖 OpenSSL 3.0.x）。
  4. `mkdir -p /data && chown node:node /data`，**不写 `VOLUME`**、**不写 `HEALTHCHECK`**。
  5. `pnpm deploy` 失败则退化到 `COPY --from=prod-deps /app/node_modules`，把实际路径写进文件注释。
  6. `.dockerignore` 按研究 §3.5，**不得**忽略 `apps/api/prisma/migrations`。
- **verify**:
  - `<automated>cd d:/workSpace/HomeWeave/homeweave; corepack pnpm validate:dockerfile; if ($LASTEXITCODE -ne 0) { exit 1 }; 'ok'</automated>`（依赖 Task 4，执行顺序可先 4 后 1）
- **acceptance**: 静态校验通过；最终阶段无 `COPY . .`、无 `latest`、有 `USER node`、有 `EXPOSE 8099`。

### Task 2 — 镜像断言脚本（8 条）

- **read_first**: `02-RESEARCH.md` §3.2、§3.3、§3.5
- **files**: `scripts/ci/assert-image.sh`
- **action**: 脚本接 `$1`=镜像引用，`set -eu`，每条打印 `✓/✗`，任一失败 exit 1。**容器清理必须用 `trap 'docker rm -f "$cid" 2>/dev/null || true' EXIT`**——`set -e` 下失败即刻退出，"末尾清理"在失败路径不可达，容器会泄漏：
  1. devDependencies 缺失：`node_modules/{typescript,@nestjs/cli,jest,eslint,ts-node,prisma}` 均不存在。
  2. `src/`、`*.spec.ts` 缺失（排除 `node_modules`）。
  3. `*.map` 缺失（排除 `node_modules`）。
  4. 产物在位：`dist/main.js`、Prisma Client 生成目录、`prisma/migrations/*/migration.sql`。
  5. **条件性**引擎架构：读宿主仓库的 `apps/api/prisma/ENGINE_DECISION`；为 `NATIVE_ENGINE` 时断言引擎文件名与 `node -p process.arch` 成对匹配；为 `RUST_FREE` 时打印 `- skipped (RUST_FREE)`；文件缺失或取值非法则 **exit 1**（不允许静默跳过）。
  6. 启动：`docker run -d` → 等日志出现 `Nest application successfully started` → `docker inspect` 断言 `State.Running == true`。
  7. **密钥（history）**：`docker history --no-trunc "$1"` 输出匹配 `ghp_|github_pat_|password=|secret=|BEGIN [A-Z ]*PRIVATE KEY` 即失败。
  8. **密钥（文件系统）**：镜像内 `find / -path '*/node_modules/*' -prune -o -type f \( -name '.env' -o -name '.env.*' -o -name '*.pem' -o -name '*.key' \) -print` 非空即失败。
- **verify**:
  - `<automated>cd d:/workSpace/HomeWeave/homeweave; if (-not (Test-Path scripts/ci/assert-image.sh)) { exit 1 }; $s = Get-Content scripts/ci/assert-image.sh -Raw; foreach ($k in 'history --no-trunc','Nest application successfully started','ENGINE_DECISION','.env','*.map','migrations',"trap ",'RUST_FREE') { if ($s -notmatch [regex]::Escape($k)) { Write-Host "missing check: $k"; exit 1 } }; if (Get-Command bash -ErrorAction SilentlyContinue) { bash -n scripts/ci/assert-image.sh; if ($LASTEXITCODE -ne 0) { Write-Host 'bash syntax error'; exit 1 }; 'ok: 8 checks present, syntax ok' } else { 'ok: 8 checks present; bash -n SKIPPED (no bash on this host) - record as unknown in SUMMARY' }</automated>`
- **acceptance**: 8 条检查字面存在；**不得**在 SUMMARY 声称本机跑过容器断言。

### Task 3 — 单一构建命令（fail-fast）

- **read_first**: `02-RESEARCH.md` §二（本机 docker 缺失实测）
- **files**: `scripts/build-image.mjs`、`package.json`
- **action**: 新增 `"build:image": "node scripts/build-image.mjs"`：
  1. 探测 `docker buildx version`；缺失则打印 `✗ docker is not available on this machine; image builds are CI-only (see docs/23)` 并 `exit 1`。
  2. 存在则 `docker buildx build --platform linux/amd64 --load -f Dockerfile -t homeweave-ha-app:local .`。
  3. 版本号只读 `homeweave_app/config.yaml` 的 `version`（**不得**读 `apps/api/package.json`）。
- **verify**:
  - `<automated>cd d:/workSpace/HomeWeave/homeweave; corepack pnpm build:image 2>&1 | Tee-Object -Variable out | Out-Null; if ($LASTEXITCODE -ne 1) { Write-Host "expected exit 1 (no docker), got $LASTEXITCODE"; exit 1 }; if ($out -notmatch 'image builds are CI-only') { Write-Host 'error message missing'; exit 1 }; 'ok: fail-fast with exit 1'</automated>`
- **acceptance**: 本机 exit **1**（不是"非零即可"）且错误信息含 `image builds are CI-only`；脚本内不读 `apps/api/package.json`。

### Task 4 — Dockerfile 静态校验（本地可闭环，IMG-05）

- **read_first**: `scripts/validate-app-metadata.mjs`（错误输出风格）
- **files**: `scripts/validate-dockerfile.mjs`、`scripts/validate-dockerfile.test.mjs`、`package.json`
- **action**: 新增 `"validate:dockerfile": "node scripts/validate-dockerfile.mjs"`，零依赖静态检查，每类缺陷单独报错 exit 1：
  1. ≥3 个 `FROM` 阶段且最后一个是 `AS runtime`。
  2. 最终阶段含 `USER node`（或非 root 用户名），不含 `USER root`。
  3. 最终阶段不得出现 `COPY . .`。
  4. `FROM` 镜像必须带 tag 且非 `latest`。
  5. 不得出现 `ARG`/`ENV`/`COPY` 携带疑似密钥变量名（`(?i)(token|secret|password|private_key|api_key)`）。
  6. 必须存在 `COPY --from=build` 与 `--from=prod-deps` 各至少一次；`.dockerignore` 存在且含 `.env`、`*.pem`、`*.key`、`secrets`。
  7. 成功打印 `✓ dockerfile checks passed (<n> rules)`。
- **verify**:
  - `<automated>cd d:/workSpace/HomeWeave/homeweave; corepack pnpm validate:dockerfile; if ($LASTEXITCODE -ne 0) { exit 1 }; 'ok'</automated>`
  - `<automated>cd d:/workSpace/HomeWeave/homeweave; node --test scripts/validate-dockerfile.test.mjs; if ($LASTEXITCODE -ne 0) { exit 1 }; 'ok'</automated>`
- **acceptance**: 6 类缺陷各有一条失败用例（喂入临时字符串，不改真实 Dockerfile）；合法输入 exit 0。

### Task 5 — 接入统一门禁

- **files**: `package.json`、`scripts/lint-workspace.mjs`
- **action**: `pnpm lint` 内部调用 `validate:dockerfile`；`pnpm test` 收编 `validate-dockerfile.test.mjs`。
- **verify**:
  - `<automated>cd d:/workSpace/HomeWeave/homeweave; corepack pnpm lint; if ($LASTEXITCODE -ne 0) { exit 1 }; corepack pnpm test; if ($LASTEXITCODE -ne 0) { exit 1 }; corepack pnpm check:app; if ($LASTEXITCODE -ne 0) { exit 1 }; 'ok'</automated>`
- **acceptance**: 三条全绿；`test:app` 仍 66/66，新增用例数写进 SUMMARY。
