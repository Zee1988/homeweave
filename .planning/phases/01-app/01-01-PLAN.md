<threat_model>
ASVS 等级 L1；阻断阈值 = high severity。本阶段无网络、无认证入口、无密钥，攻击面集中在"元数据被 Supervisor 静默误读"这一类，因此威胁以 Tampering 为主。

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 仓库内容 → Supervisor 递归扫描 | 仓库里任何 config.* 都会被当作 App 定义加载，不受本仓控制 |
| 元数据源 → 生成物 | JSON 源是唯一写入口；手工编辑生成物会造成静默漂移 |
| 生成物 → Phase 2 镜像发布 | image 前缀与 version 值是跨阶段契约 |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
