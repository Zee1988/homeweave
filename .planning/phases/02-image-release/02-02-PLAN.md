# 02-02 — Prisma Client 与初始迁移

<threat_model>
| ID | STRIDE | 严重度 | 威胁 | 缓解 | 验证 |
|---|---|---|---|---|---|
| T-02-02 | Denial of Service | high | amd64 生成的 Prisma 原生引擎进入 arm64 镜像，构建全绿、容器首次查询即崩（docs/21:134） | 先取证据判断引擎形态；需要则 `binaryTargets` 覆盖 amd64+arm64，并在镜像内断言引擎名与 `process.arch` 匹配 | Task 3 探测输出写入 SUMMARY；02-03 断言按结论落地 |
</threat_model>

## 目标

IMG-02 要求镜像内含 **Prisma Client** 与 **迁移文件**。两者必须先在本仓库真实存在，02-03 才有东西可 COPY。本计划还要产出一个**关于 Prisma 原生引擎的事实判定**，因为它决定 arm64 镜像是否为运行期炸弹。

## 必须先做的判定（不要跳过）

Task 3 不是"配一下 binaryTargets"，而是**先取证据**：

- 若 `prisma generate` 后**实际生成目录**出现 `*.so.node` / `libquery_engine*` 等原生二进制 → 原生引擎仍在 → **必须**配置 `binaryTargets`，T-02-02 的缓解措施生效，`ENGINE_DECISION` 写 `NATIVE_ENGINE`。
- 若完全没有原生二进制 → client 为纯 JS 形态 → `binaryTargets` 无意义，**删除该配置**，`ENGINE_DECISION` 写 `RUST_FREE`，并在 SUMMARY 记录「T-02-02 判定 N/A，证据：<命令与输出>」。此时 02-03 的引擎断言由该文件驱动降级为 `- skipped (RUST_FREE)`，**不是**靠人去删代码（上一版缺陷：跨 plan 的"记得删掉"没人检查）。

两种结论都要留命令与输出原文，不允许凭记忆断言。

### Task 3 — 引擎形态判定 + 确定 binaryTargets + 落盘 ENGINE_DECISION

- **files**: `apps/api/prisma/schema.prisma`（可能修改）、`apps/api/prisma/ENGINE_DECISION`（新建）
- **action**:
  1. 先确定 **client 实际生成目录**：`schema.prisma` 的 generator 若写了 `output`，用之；否则 Prisma 默认生成到 `node_modules/.prisma/client`（pnpm 下通常提升到仓库根）。**不得假定它在 `apps/api` 下**——上一版探测路径写的是 `apps/api` 递归，那会永远探测不到引擎、得出假的 `RUST_FREE` 结论。
  2. 以 `DATABASE_URL=file:.tmp/dev.db` 运行 `prisma generate`。
  3. 在**上一步确认的目录**内探测原生二进制（`*.so.node`、`libquery_engine*`、`query_engine-*`）。
  4. 按判定处置：有原生二进制则 `binaryTargets = ["native", "debian-openssl-3.0.x", "linux-arm64-openssl-3.0.x"]` 并重跑 generate；完全没有则删除该行。
  5. 把结论写入 `apps/api/prisma/ENGINE_DECISION`：内容**恰好一行**，`NATIVE_ENGINE` 或 `RUST_FREE`（无其它文字）。这是 02-03 引擎断言唯一的开关，也是跨 plan 的可检查契约。
  6. 探测命令与输出原文记入执行 SUMMARY。
- **verify**:
  - `<automated>cd d:/workSpace/HomeWeave/homeweave; $env:DATABASE_URL='file:.tmp/dev.db'; corepack pnpm --filter @homeweave/api exec prisma generate; if ($LASTEXITCODE -ne 0) { exit 1 }; $s = Get-Content apps/api/prisma/schema.prisma -Raw; $cands = @(); if ($s -match 'output\s*=\s*"([^"]+)"') { $cands += $matches[1] }; $cands += 'apps/api/node_modules/.prisma/client','node_modules/.prisma/client'; $gen = $null; foreach ($c in $cands) { if (Test-Path $c) { $gen = $c; break } }; if (-not $gen) { Write-Host ("generated client dir not found in: " + ($cands -join ', ')); exit 1 }; Write-Host "client dir: $gen"; $native = Get-ChildItem -Path $gen -Recurse -File -ErrorAction SilentlyContinue | Where-Object { $_.Name -like '*.so.node' -or $_.Name -like 'libquery_engine*' -or $_.Name -like 'query_engine-*' }; $expected = if ($native) { 'NATIVE_ENGINE' } else { 'RUST_FREE' }; $actual = (Get-Content apps/api/prisma/ENGINE_DECISION -Raw -ErrorAction SilentlyContinue); if ($null -eq $actual) { Write-Host 'ENGINE_DECISION missing'; exit 1 }; $actual = $actual.Trim(); if ($actual -ne $expected) { Write-Host "ENGINE_DECISION mismatch: file=$actual probe=$expected"; exit 1 }; 'ok: ' + $expected</automated>`
  - `<automated>cd d:/workSpace/HomeWeave/homeweave; $s = Get-Content apps/api/prisma/schema.prisma -Raw; $d = (Get-Content apps/api/prisma/ENGINE_DECISION -Raw).Trim(); if ($d -eq 'RUST_FREE' -and $s -match 'binaryTargets') { Write-Host 'RUST_FREE but binaryTargets kept'; exit 1 }; if ($d -ne 'NATIVE_ENGINE' -and $d -ne 'RUST_FREE') { Write-Host "invalid ENGINE_DECISION: $d"; exit 1 }; 'ok'</automated>`
- **acceptance**: 结论有命令与输出支撑；`ENGINE_DECISION` 恰为两个合法值之一且与探测结果一致；判定 `RUST_FREE` 时 `schema.prisma` 不得残留 `binaryTargets`。

## 已知风险

- Prisma 7.x 的 generator 名称与引擎形态在不同次版本间有变化。Task 3 若发现 `prisma-client-js` 已不可用，可改用 `prisma-client` + 显式 `output`，但**必须同步更新 02-03 的 COPY 路径与 import 路径**，并在 SUMMARY 记录该偏离。
- SQLite 在 Windows 与本机文件锁行为与容器内不同；迁移可应用性只证明 SQL 正确，不证明 `/data` 挂载后仍正确（归 Phase 04）。
