# HomeWeave HA App templates

These are **specification examples**, not a ready-to-install release. Files use `.example` suffixes so Home Assistant does not mistake this documentation package for a live app repository. Before release, the coding agent must compare them with the current official Home Assistant Apps example, implement the real Dockerfile/startup, validate `config.yaml`, build multi-architecture images, and test on a real Home Assistant OS installation.

Do not copy placeholder `<owner>/<repo>` values into a release. Do not expose the native API port until its authentication and authorization have been implemented and tested.
